# agent_reviews/

Log of AI-assisted steps and reviewer findings. Each `/review` run and any
substantive AI-assisted change should leave a dated note here recording what was
done, which reviewers ran, the findings by severity (Critical > High > Medium >
Low), the overall verdict (Ready / Needs attention / Needs work), and how
Critical or High findings were resolved.

This directory is tracked so the audit trail lives with the code.
