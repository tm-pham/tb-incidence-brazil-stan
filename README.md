# tb-incidence-brazil-stan

Bayesian modelling of tuberculosis (TB) incidence in Brazil using [Stan](https://mc-stan.org/).

## Overview

_Work in progress._ This repository contains the data preparation, Stan models,
and analysis code for estimating TB incidence in Brazil.
