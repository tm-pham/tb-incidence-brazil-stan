# literature/open_access_pdfs/

Open-access source PDFs (and their supplements). Unlike `private_pdfs/`, these may
be **committed** when the licence allows (e.g. CC-BY for PLOS Global Public
Health). Commit the PDF here so it travels with the repo and is readable in a
fresh container / web session; if a paper's licence does not permit
redistribution, keep it in `private_pdfs/` instead.

Most relevant to the current state-month scope:

- Chitwood et al. 2025, IJE (`chitwood2025disruptions`) - the monthly base model.
  Check the OUP/IJE licence before committing; the **supplement (Table S2: priors
  and delay distributions)** is what the modelling needs most.
- Chitwood et al. 2022, PLOS Global Public Health (`chitwood2022spatial`,
  CC-BY) - out of scope for the model, but its natural-history likelihood and the
  ill-defined-cause death adjustment are informative.
- Chitwood et al. 2021, Epidemics (`chitwood2021bes`) - death-adjustment
  structure; check the licence.

See `literature/references.bib` for citation keys and
`literature/agent_literature_instructions.md` for what to extract.
